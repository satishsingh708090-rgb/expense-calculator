# 💰 Expense Calculator

A simple and beginner-friendly Expense Calculator built using HTML, CSS, and JavaScript.

## 🚀 Features

- Enter total income
- Enter total expense
- Calculate remaining balance
- Simple and responsive design
- Beginner-friendly project

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

expense-calculator/
├── index.html
├── README.md
├── css/
│   └── style.css
└── js/
    └── script.js

## ▶️ How to Run

1. Open the project folder.
2. Open `index.html` in a web browser.
3. Enter your income.
4. Enter your expense.
5. Click **Calculate**.
